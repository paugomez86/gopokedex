## About The Project

REPL app made in Golang that emulates a simple Pokedex system. Powered by [PokeApi](https://pokeapi.co/).

Created as part of the referenced [Boot.dev course](https://www.boot.dev/courses/build-pokedex-cli-golang).

<br>

<!-- GETTING STARTED -->
## Prerequisites

The only requisite is [Go 1.26.0+](https://go.dev/doc/install).
